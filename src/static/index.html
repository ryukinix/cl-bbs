Source Code

Check this new textboard written in Common Lisp called cl-bbs at github. This version is fully refactored, robustly tested, and packaged with local sandbox package locks. You can also view the original MIT Scheme draft of SchemeBBS at SchemeBBS.

Software Stack

cl-bbs is written in Common Lisp (running on SBCL), Cloudflare is used as a CDN/reverse proxy and the whole system runs on Docker containers. There's no SQL database; messages are stored as Lisp S-expression objects in plain text files. This stack is extremely robust. This codebase was adapted from the original MIT Scheme SchemeBBS as a high-quality Common Lisp port, with full credit given to its original author.
